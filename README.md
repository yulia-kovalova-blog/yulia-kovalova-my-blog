# Перша парта

Особистий блог Юлії Ковальової, вчительки початкових класів.

Сайт: https://yulia-kovalova-blog.github.io/yulia-kovalova-my-blog/

## Як редагувати

1. Відкрийте сайт і натисніть **«Вхід для вчителя»** внизу бокового меню.
2. Вставте ключ доступу GitHub (fine-grained token з дозволом *Contents: Read and write* лише для цього сховища).
3. Редагуйте все прямо на сайті. Зміни з'являються для відвідувачів приблизно за 1–2 хвилини.

Тексти сайту зберігаються у `data/site.json`, файли матеріалів у `files/`, обкладинки у `covers/`, фото й логотип у `img/`.
